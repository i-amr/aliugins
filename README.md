# Plugins

### [iMoji](https://github.com/i-amr/aliugins/releases/download/v1.0.0/iMoji.zip)
Replaces Discord's default Twemoji with Apple's emojis.

### [TextPurge](https://github.com/i-amr/aliugins/releases/download/v1.0.0/TextPurge.zip)
Purges chat messages filtered by user and message limit using a slash command.

### [TextGesture](https://github.com/i-amr/aliugins/releases/download/v1.0.0/TextGesture.zip)
Adds swipe gestures to the text input box:
* **Swipe Right:** Paste text
* **Swipe Left:** Clear text

## Installation
1. Download the `.zip` file of the plugin you want from the [Releases](https://github.com/i-amr/aliugins/releases/) page.
2. Move the file into your `Aliucord/plugins` folder.
3. Restart Aliucord.
